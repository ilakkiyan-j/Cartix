Cartix Documentation

Complete engineering reference for the Cartix Model Context Protocol (MCP) connector for WooCommerce.

Overview & Problem Statement #

Modern merchants maintain their mission-critical business data inside e-commerce engines like WooCommerce. However, autonomous AI agents cannot directly query raw store databases without encountering massive security, reliability, and context-window limitations.

Cartix serves as the secure, read-only bridge between AI agents and WooCommerce REST endpoints.

Strict Responsibility Split
Cartix handles authentication, rate limiting, retries, input validation, and PII sanitization. The AI agent focuses purely on multi-turn reasoning and conversational delivery.

Quick Start & Installation #

Follow these steps to run Cartix locally on your development machine:

bash — installation 
# 1. Clone repository
git clone https://github.com/ilakkiyan-j/Cartix.git
cd Cartix

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env

# 4. Build TypeScript bundle
npm run build

# 5. Start the server
npm start

Claude Desktop Integration #

To give Claude Desktop direct access to your WooCommerce store through Cartix, configure your claude_desktop_config.json file:

claude_desktop_config.json 
{
  "mcpServers": {
    "cartix": {
      "command": "node",
      "args": ["/path/to/cartix/dist/src/index.js"],
      "env": {
        "WOOCOMMERCE_URL": "https://store.example.com",
        "WOOCOMMERCE_CONSUMER_KEY": "ck_230682712bc9678bb7dbcaf0bbec12f210cbcca1",
        "WOOCOMMERCE_CONSUMER_SECRET": "cs_99675a615d5023075f0ade63b2c5abace655191a",
        "MCP_TRANSPORT": "stdio"
      }
    }
  }
}

Architecture & Transports #

Cartix conforms strictly to the Model Context Protocol specification published by Anthropic. Communication flows through standard JSON-RPC 2.0 messages across three selectable transports.

TransportBest ForSpecification
stdioLocal Desktop AI (Claude Desktop, Cursor)Standard input/output stream piping
streamable-httpWeb agents, microservices, cloud deploymentsStateless chunked HTTP endpoint at /mcp
sseBrowser agents, streaming interfacesServer-Sent Events streaming at /sse

Authentication & Security Model #

Cartix implements multi-layered security controls to protect merchant infrastructure:

1. HTTPS Basic Auth

Credentials are encoded into standard Basic Auth headers (base64(consumer_key:consumer_secret)) over encrypted TLS channels.

2. Automatic PII Redaction

Customer data is transformed before tool responses are returned:

  • Email Masking: alexander@example.com becomes a***r@example.com.
  • Physical Address Stripping: Street names and apartment numbers are purged; only general country/state is retained if needed.

3. Secret Redaction in Logs

All internal loggers scrub sensitive token patterns using regular expressions (\bck_[a-zA-Z0-9_-]+ and \bcs_[a-zA-Z0-9_-]+) to prevent accidental disk or console leakages.

Rate Limiting & Reliability #

To prevent crashing upstream store servers, Cartix features:

  • In-Memory Token Bucket: Configurable capacity and refill rates regulate outbound request bursts.
  • Exponential Backoff with Full Jitter: Retries transient 5xx errors and network timeouts with randomized sleep delays.
  • 429 Retry-After Parsing: Honors upstream WooCommerce rate limit headers explicitly.

MCP Tools Specification #

search_orders #

Search WooCommerce orders with status filters, customer queries, and date ranges.

FieldTypeDescription
statusstring (optional)pending, processing, on-hold, completed, cancelled
afterstring (optional)ISO 8601 date cutoff
limitnumber (optional)1–100 (default: 20)

get_order #

Retrieve detailed order information by ID, including items and sanitized billing.

search_products #

Query store products by title, keyword, or SKU code.

get_product #

Retrieve single product specifications, inventory count, and pricing.

get_inventory #

Inspect store-wide stock levels with deterministic low_stock_only filtering.

AI Demo Agent #

Cartix includes a ready-to-run multi-turn AI agent in demo/agent.ts. The agent interacts over live MCP tools using Google Gemini (gemini-3.8-flash) with automatic fallback to local heuristic reasoning.

bash — run demo 
# Run interactive demo
npm run demo

# Run all 6 evaluation scenarios automatically
npm run demo -- --all

Testing & Quality Assurance #

The test suite contains 60 automated tests across 10 test suites, covering schema validation, error mapping, pagination bounding, rate limiting, and end-to-end MCP integration.

bash — vitest 
# Run all unit and integration tests
npm test

# Run tests in watch mode
npm run test:watch

Docker Deployment #

Deploy Cartix inside a hardened, unprivileged Node 20 Alpine container:

bash — docker 
# Build container image
docker build -t cartix-mcp .

# Run container with environment variables
docker run -p 3000:3000 \
  -e WOOCOMMERCE_URL=https://store.example.com \
  -e WOOCOMMERCE_CONSUMER_KEY=ck_... \
  -e WOOCOMMERCE_CONSUMER_SECRET=cs_... \
  cartix-mcp

Explicit Boundaries & Limitations #

Zero Mutation Guarantee
Cartix will strictly refuse any requests to create or update orders, delete inventory items, issue refunds, or execute unvalidated writes.
